## RESPONSIVE DESIGN NOTES

While specific breakpoints aren't visible in the Figma, here are recommended approaches:

### Desktop (1200px+):
- Full layout as designed
- Multi-column grids

### Tablet (768px - 1199px):
- Reduce side padding
- 2-column grid for trending cards
- Single column for topic cards (scroll)

### Mobile (< 768px):
- Single column layout
- Stack all cards vertically
- Hamburger menu for navigation
- Reduce font sizes by 10-15%
- Hero text: smaller headline (~32-36px)

## INTERACTIONS & ANIMATIONS

### Hover States:
- **Buttons:** Scale (1.02-1.05) or background color darken
- **Cards:** Lift effect (translateY -4px) + shadow increase
- **Links:** Underline or color change
- **Social Icons:** Lift + background darken

### Transitions:
- Duration: 0.3s
- Easing: ease or ease-in-out

### Potential Animations:
- Fade in on scroll for cards
- Smooth scroll for navigation
- Image zoom on card hover (subtle)

## ACCESSIBILITY CONSIDERATIONS

### Color Contrast:
- Ensure cyan text on white meets WCAG AA standards
- Black text on white: Excellent contrast
- White text on cyan: Check and adjust if needed

### Focus States:
- Add visible focus outline for keyboard navigation
- Focus color: Cyan with 2px outline

### Alt Text:
- All images need descriptive alt text
- Decorative images: alt=""

- Use proper heading hierarchy (h1, h2, h3)
